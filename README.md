# App Móvil - Salud Mental

##  Descripción

Aplicación móvil desarrollada con React Native que permite a los usuarios registrarse, iniciar sesión y acceder a contenido relacionado con salud mental.

##  Tecnologías

* React Native (Expo)
* JavaScript
* Supabase

##  Funcionalidades

* Registro de usuarios
* Inicio de sesión
* Navegación entre pantallas
* Conexión con base de datos

##  Cómo ejecutar

```bash id="pwejsh"
npm install
npx expo start
```
